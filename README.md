
# Litespeed


We were inspired by Lightspeed's fantastic payments platform to design our own powerful Point-of-Sale application, Litespeed (pun intended). 

Litespeed is tailor-made to streamline operations for fast food restaurants. With Litespeed, you will be able to setup a POS for your physical storefront, intake and process orders from customers, print receipts, and gain valuable business insights!

## Run Locally

Clone the project

```bash
  git clone https://github.com/itsandytran/Litespeed
```

Go to the project directory

```bash
  cd Litespeed
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npx expo start
```


## Tech Stack

- React Native (Expo)
- Drizzle ORM
- SQLite
